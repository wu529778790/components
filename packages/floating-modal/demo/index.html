floating-modal 演示站 @wu529778790/floating-modal

极简 · 零依赖 · 赞助 / 公告弹窗。点「立即弹出」或改参数后重新弹出。

参数面板（改完点「立即弹出」生效）

手动弹出的 show() 不受频率限制；自动弹出才受 frequency 控制

快速上手

方式零：CDN 零代码（一条标签即自动弹出）

<link rel="stylesheet" href="https://unpkg.com/@wu529778790/floating-modal@latest/dist/floating-modal.css">
<script src="https://unpkg.com/@wu529778790/floating-modal@latest/dist/index.umd.js"></script>
<!-- 无需任何 JS，默认赞助弹窗自动弹出（关闭后 7 天不再打扰） -->

方式一：NPM 安装

pnpm add @wu529778790/floating-modal
import FloatingModal from '@wu529778790/floating-modal'
import '@wu529778790/floating-modal/style.css'

new FloatingModal()  // 零配置，默认话术 + 默认赞赏码
// 或自定义：
new FloatingModal({
  title: '站点公告',
  content: '本站将于 8 月 20 日凌晨迁移服务器…',
  qr: { src: 'https://.../qrcode.png' },
  frequency: 7
})

CDN + 自定义参数

<script>
  window.__FLOATING_MODAL_OPTIONS__ = {
    title: '小水管请求支援',
    qr: { src: 'https://.../qrcode.png' }
  }
</script>
<script src="https://unpkg.com/@wu529778790/floating-modal@latest/dist/index.umd.js"></script>
<!-- 完全禁用自动弹出：给 <html> 加 data-fm-auto="false" -->
弹窗为模态（遮罩 + 点遮罩关闭 + Esc 关闭）。频率控制存于本地（每次/每天/关闭后 N 天）， 默认关闭后 7 天内不再打扰，避免烦人。
