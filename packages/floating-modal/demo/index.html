floating-modal 演示站 <floating-modal> Web Component

极简 · 零依赖 · 赞助 / 公告弹窗。改参数后点「立即弹出」生效。

参数面板（改完点「立即弹出」生效）

快速上手（Script 注入 · 改一处全站生效）

方式一：CDN 一行引入（零配置，自动弹出默认弹窗）

<script src="https://unpkg.com/@wu529778790/floating-modal@latest/dist/floating-modal.wc.js"></script>
<!-- 无需任何标签/JS，进入页面自动弹出默认赞助弹窗 -->

方式二：声明式标签（默认连接即弹出；auto-show="false" 时手动调用 show()）

<floating-modal
  auto-show="false"
  title="站点公告"
  content="本站将于 8 月 20 日凌晨迁移服务器…"
  qr-src="https://.../qrcode.png">
</floating-modal>
<script src="https://unpkg.com/@wu529778790/floating-modal@latest/dist/floating-modal.wc.js"></script>
<script>document.querySelector('floating-modal').show()</script>

方式三：全局配置

<script>
  window.__FLOATING_MODAL_OPTIONS__ = {
    title: '小水管请求支援',
    qr: { src: 'https://.../qrcode.png' }
  }
</script>
<script src="https://unpkg.com/@wu529778790/floating-modal@latest/dist/floating-modal.wc.js"></script>

方式四：NPM 双轨（React/Vue 项目照旧）

pnpm add @wu529778790/floating-modal
import FloatingModal from '@wu529778790/floating-modal'
import '@wu529778790/floating-modal/style.css'
new FloatingModal()
全部支持属性：auto-show title content content-html qr-src qr-alt width delay z-index mask-closable close-on-esc show-close theme-bg/-accent/-radius/-border/-overlay/-title-color/-text-color
不想自动弹出：给 <html> 加 data-fm-auto="false"。 样式已隔离在 shadow DOM，外部可用 --fm-* 变量覆盖。
备选（GitHub 直连，push 即生效、不依赖 npm 发布）： https://cdn.jsdmirror.com/gh/wu529778790/components@main/cdn/floating-modal.wc.js
