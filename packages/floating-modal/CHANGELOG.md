# Changelog

## 0.1.2 - 2026-08-17

### Changed
- 移除频率控制（frequency）功能：每次进入页面都弹出，关闭只对当前这次生效
- 更新默认赞助话术：「小水管服务器扛不住了，如果本站对你有用就支持一下，让它再多扛几天。」

## 0.1.0 - 2026-08-17

### Features
- 首个版本：赞助 / 公告弹窗组件
- 默认赞助话术（自嘲 + 真诚）+ 内置赞赏码二维码，零配置可用
- 频率控制：每次 / 每天一次 / 关闭后 N 天不再打扰
- 点遮罩关闭、Esc 关闭、右上角 X
- `--fm-*` CSS 变量主题化，支持正文 HTML
- CDN 引入即自动弹出，支持 `window.__FLOATING_MODAL_OPTIONS__` 全局配置
- tsup 构建 ESM + CJS + IIFE 三格式，输出 `.d.ts`
