floating-unlock 演示站 <floating-unlock> Web Component

自愿支持弹窗：弹出固定小程序码，用户想看就看、想关随时关。纯静态，运行时零后端请求。

参数（可选，改完点「打开弹窗」生效）

点击下方按钮打开弹窗（可随时关闭）

弹窗纯静态展示：无接口调用、无校验，用户自愿扫码观看。

接入方式

方式一：声明式标签（推荐）

<floating-unlock></floating-unlock>
<script src="https://unpkg.com/@wu529778790/floating-unlock@latest/dist/floating-unlock.wc.js"></script>
<script>
  const unlockEl = document.querySelector('floating-unlock')

  // 在合适的位置打开弹窗；用户可随时关闭（× / 遮罩 / Esc）
  unlockEl.show()
</script>

方式二：NPM

pnpm add @wu529778790/floating-unlock
import FloatingUnlock from '@wu529778790/floating-unlock'
import '@wu529778790/floating-unlock/style.css'

const unlock = new FloatingUnlock()
unlock.show()   // 打开弹窗；close() 关闭
完全静态：组件不再调用任何后端接口（无出码/轮询/验票），二维码是写死的 固定小程序激励页码图片（pages/reward-unlock/index，release 版，无参数）， 由 scripts/generate-qr.mjs 一次性生成并托管在图床。旧调用 await el.unlock() 仍可用，但只负责打开弹窗并立即返回，不再阻塞业务。
全部支持属性：qr-src title content content-html width z-index theme-bg/-accent/-radius/-border/-overlay/-title-color/-text-color。 本组件不自动弹出——由业务方在合适位置调用 el.show() 触发。 样式已隔离在 shadow DOM，外部可用 --fu-* 变量覆盖。
