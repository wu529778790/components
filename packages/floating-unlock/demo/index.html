floating-unlock 演示站 <floating-unlock> Web Component

通用解锁弹窗：扫码看视频广告后放行业务。强制不可关，看完才能继续。点右侧按钮即可体验。

参数（可选，改完点「触发解锁」生效）

用于小程序端展示来源 / 广告统计

点击下方按钮，体验强制解锁

看完小程序视频后自动放行（这里演示解锁结果）。

接入方式

方式一：声明式标签 + 业务方调用 unlock()（推荐）

<floating-unlock api-base="https://wx-auth.shenzjd.com" site-id="panhub.shenzjd.com"></floating-unlock>
<script src="https://unpkg.com/@wu529778790/floating-unlock@latest/dist/floating-unlock.wc.js"></script>
<script>
  const unlockEl = document.querySelector('floating-unlock')

  // 在需要解锁的动作处调用，resolve(true) 才放行业务
  async function continueSearch() {
    const ok = await unlockEl.unlock()
    if (ok) { /* 继续搜索 */ }
  }
</script>

方式二：NPM 双轨（React/Vue 项目照旧）

pnpm add @wu529778790/floating-unlock
import FloatingUnlock from '@wu529778790/floating-unlock'
import '@wu529778790/floating-unlock/style.css'

const unlock = new FloatingUnlock({ apiBase: 'https://wx-auth.shenzjd.com', siteId: 'xxx' })
const ok = await unlock.unlock()   // true=解锁成功，业务继续
if (ok) { /* 继续业务 */ }
全部支持属性：api-base site-id title content content-html width z-index theme-bg/-accent/-radius/-border/-overlay/-title-color/-text-color。 本组件为「强制解锁」场景，不自动弹出——由业务方在需要解锁的动作处调用 el.unlock() 触发。 样式已隔离在 shadow DOM，外部可用 --fu-* 变量覆盖。
