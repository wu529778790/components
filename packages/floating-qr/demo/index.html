floating-qr 演示站 @wu529778790/floating-qr

极简 · 零依赖 · 公众号 + 赞赏码浮窗。右侧悬浮的卡片就是组件本身，修改参数实时生效。

参数面板（实时生效）

勾选后关闭写入 localStorage，刷新不再出现；不勾选则刷新必出现
<768px 时自动不渲染

快速上手

方式零：CDN 零代码（最快 · 引一条标签即自动出现）

<link rel="stylesheet" href="https://unpkg.com/@wu529778790/floating-qr@latest/dist/floating-qr.css">
<script src="https://unpkg.com/@wu529778790/floating-qr@latest/dist/index.umd.js"></script>
<!-- 无需任何 JS，浮窗自动出现，用内置公众号 + 赞赏码 -->

方式一：NPM 安装（推荐）

pnpm add @wu529778790/floating-qr
import FloatingQR from '@wu529778790/floating-qr'
import '@wu529778790/floating-qr/style.css'

new FloatingQR()  // 零配置，或传参数自定义
// new FloatingQR({ wechat: { src, title }, donate: { src, title }, position })

方式二：CDN + 自定义参数（不想用默认图时）

<link rel="stylesheet" href="https://unpkg.com/@wu529778790/floating-qr@latest/dist/floating-qr.css">
<script>
  window.__FLOATING_QR_OPTIONS__ = {
    wechat: { src: 'https://.../wechat.jpg', title: '公众号' },
    donate: { src: 'https://.../donate.png', title: '赞赏码' }
  }
</script>
<script src="https://unpkg.com/@wu529778790/floating-qr@latest/dist/index.umd.js"></script>

<!-- 完全禁用自动初始化：给 <html> 加 data-fq-auto="false" 再手动 new -->
