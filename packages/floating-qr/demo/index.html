floating-qr 演示站 <floating-qr> Web Component

极简 · 零依赖 · 公众号 + 赞赏码浮窗。右侧悬浮卡片即组件实例，面板改参数即时热更新。

参数面板（操作 <floating-qr> 属性，即时生效）

勾选后关闭写入 localStorage，刷新不再出现；不勾选则刷新必出现
<768px 时自动不渲染
勾选后可设置背景/文字颜色；不勾选完全跟随系统深浅色
对应 link-hrefs 属性，逗号分隔 URL

快速上手（Script 注入 · 改一处全站生效）

方式一：CDN 一行引入（零配置，自动出现默认浮窗）

<script src="https://unpkg.com/@wu529778790/floating-qr@latest/dist/floating-qr.wc.js"></script>
<!-- 无需任何标签/JS，自动注入默认公众号 + 赞赏码浮窗 -->

方式二：声明式标签（按需定制，属性即时热更新）

<floating-qr
  position="left-bottom"
  theme-accent="#e04040"
  wechat-title="公众号"
  donate-title="赞赏码">
</floating-qr>
<script src="https://unpkg.com/@wu529778790/floating-qr@latest/dist/floating-qr.wc.js"></script>

方式三：全局配置（复杂参数：二维码 URL、主题色）

<script>
  window.__FLOATING_QR_OPTIONS__ = {
    wechat: { src: 'https://.../wechat.jpg', title: '公众号' },
    donate: { src: 'https://.../donate.png', title: '赞赏码' },
    theme: { bg: '#fff', accent: '#333' }
  }
</script>
<script src="https://unpkg.com/@wu529778790/floating-qr@latest/dist/floating-qr.wc.js"></script>

方式四：NPM 双轨（React/Vue 项目照旧）

pnpm add @wu529778790/floating-qr
import FloatingQR from '@wu529778790/floating-qr'
import '@wu529778790/floating-qr/style.css'
new FloatingQR()
全部支持属性：position close-persistence hide-on-mobile z-index wechat-src/-title/-desc donate-src/-title/-desc link-hrefs theme-bg theme-accent theme-radius theme-border
不想自动注入：给 <html> 加 data-fq-auto="false"。 样式已隔离在 shadow DOM，外部可用 --fq-* 变量覆盖。
备选（GitHub 直连，push 即生效、不依赖 npm 发布）： https://cdn.jsdmirror.com/gh/wu529778790/components@main/cdn/floating-qr.wc.js
