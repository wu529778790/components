用户头像 · 账号组件（@wu529778790/user-avatar）

未登录 → 点击头像弹出微信登录；已登录 → 头像下拉「设置 / 退出登录」→ 设置弹窗（GitHub 绑定、改昵称）

体验（点右上角头像）

本页接入真实后端（微信认证服务 https://wx-auth.shenzjd.com），无任何模拟数据。
未登录时点击头像 → 弹出微信扫码登录（关注公众号 + 验证码）；登录后即可查看 / 修改昵称、绑定 GitHub。

接入方式（本页即真实环境示例）

  • 先加载 wx-auth-sdk（UMD，注入 window.WxAuth）并初始化：
    WxAuth.init({ apiBase: 'https://wx-auth.shenzjd.com', silent: true })
  • 再引本组件单文件：
    <script src="https://unpkg.com/@wu529778790/user-avatar@latest/dist/user-avatar.wc.js"></script>
  • 同域直接 <user-avatar></user-avatar>；跨域加 api-base 指向后端。
