floating-ad 演示站 <floating-ad> Web Component

极简 · 零依赖 · 左侧广告浮窗。左侧悬浮卡片即组件实例，面板改参数即时热更新。

参数面板（操作 <floating-ad> 属性，即时生效）

默认关闭；填入文字后压首图左上角，不占行高
多条广告自上而下排列，中间自动加分隔线

快速上手（Script 注入 · 改一处全站生效）

方式一：CDN 一行引入 + 声明式标签

<floating-ad
  ad-src="https://.../ad.jpg"
  ad-title="云服务器 · 2 核 4G"
  ad-desc="新用户首年 99 元"
  ad-href="https://..."
  ad-badge="限时">
</floating-ad>
<script src="https://unpkg.com/@wu529778790/floating-ad@latest/dist/floating-ad.wc.js"></script>

多条广告：ads-json 属性

<floating-ad ads-json='[
  { "src": "https://.../a.jpg", "title": "云服务器特惠", "href": "https://..." },
  { "title": "周刊订阅", "desc": "每周一封，只讲有用的工具", "href": "https://..." }
]'></floating-ad>

全局配置（无标签时自动注入）

<script>
  window.__FLOATING_AD_OPTIONS__ = {
    ads: [
      { src: 'https://.../ad.jpg', title: '云服务器特惠', href: 'https://...' }
    ],
    position: 'left-center',
    width: 180
  }
</script>
<script src="https://unpkg.com/@wu529778790/floating-ad@latest/dist/floating-ad.wc.js"></script>

NPM 双轨（React/Vue 项目）

pnpm add @wu529778790/floating-ad
import FloatingAd from '@wu529778790/floating-ad'
import '@wu529778790/floating-ad/style.css'
new FloatingAd({ ads: [{ src: '/ad.jpg', title: '广告位', href: '/' }] })
全部支持属性：position close-persistence hide-on-mobile z-index ad-label width offset image-fit image-height ad-src/-title/-desc/-href/-target/-badge ads-json theme-bg theme-accent theme-radius theme-border
没有广告数据时不渲染任何节点；不想自动注入：给 <html> 加 data-fa-auto="false"。 样式已隔离在 shadow DOM，外部可用 --fa-* 变量覆盖。
备选（GitHub 直连，push 即生效、不依赖 npm 发布）： https://cdn.jsdmirror.com/gh/wu529778790/components@main/cdn/floating-ad.wc.js
