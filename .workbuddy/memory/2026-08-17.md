### 关键坑（复用价值高）
1. **pnpm 11 构建脚本拦截**：esbuild postinstall 被拦截会报 ERR_PNPM_IGNORED_BUILDS 且 install 退出码 1。
   解决：`pnpm-workspace.yaml` 顶部加 `allowBuilds:\n  esbuild: true`。
   ⚠️ 不是 package.json 的 pnpm.onlyBuiltDependencies（pnpm 11 已废弃该字段），也不是 allowBuilds 填字符串（要 true/false）。
2. **tsup 产物文件名** = 入口文件名（src/index.ts → dist/index.*），outExtension 只能改扩展名；CSS 不自动复制，用 `build` 脚本里 `node -e "require('fs').copyFileSync('src/styles.css','dist/floating-qr.css')"`。
3. **tsup 构建产生临时文件** `_tmp_*` 和 `tsup.config.bundled_*.mjs`，已加入 .gitignore。
4. UMD 全局可直接 new：tsup iife `globalName: 'FloatingQR'` + footer `if (typeof FloatingQR !== "undefined") { FloatingQR = FloatingQR.default || FloatingQR; }`。
